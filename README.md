## 📚 关于这个博客

这是一个~~纯Ai~~我作为prompt engineer编写的前端博客项目，记录了我作为上海交通大学物天院学生的各种感想、学习心得或是杂七杂八的东西。从零开始构建，包含完整的UI设计和交互功能。

### ✨ 核心特性

- **🎨 现代设计美学**
  - 响应式布局（手机/平板/电脑全适配）
  - 粉色调主题 + 粒子动画背景
  - 深色/浅色双模式切换
  - 毛玻璃效果卡片设计

- **🎵 沉浸式体验**
  - 背景音乐系统（可控制播放/暂停）
  - 平滑滚动和交互动画
  - 鼠标跟随粒子效果

- **📱 完整功能**
  - 个人介绍区域（头像+社交链接）
  - 文章分类和标签系统
  - 分页导航和搜索功能
  - 移动端优化菜单
